# Week 3 Reflection Draft

In Week 3, I focused on refining the portfolio rather than rebuilding it from scratch. Earlier versions helped me compare different design directions, but the final decision was to use the architectural-blue version because it felt professional, calm, and aligned with my positioning in healthcare data, master data management, data quality, governance, and responsible analytics.

One of the most important changes was making the portfolio more usable beyond the assignment. I refined the main homepage, improved the resume download experience, clarified the Analytics Lab data boundary, and added more structure to the case-study section. The Problem / Built / Result format made the work easier to scan and helped the page feel more like a data portfolio than a resume rewritten as a website.

I also created a mobile-first connect page. This was the main Week 3 addition because it supports real-world use at career fairs, networking events, and NFC sharing. The connect page is intentionally simpler than the full portfolio. It gives someone the most important information in about 15 seconds: who I am, what I do, and how to contact me.

Working with AI was useful because it helped me generate options, compare design directions, identify gaps, and implement changes quickly. At the same time, I had to use my own judgment throughout the process. Not every suggestion fit the tone I wanted. Some animations felt too distracting, some content needed to be simplified, and some visual directions did not match the professional trust I wanted the portfolio to communicate.

The biggest lesson I learned is that AI is strongest when I give it clear direction and then evaluate the output critically. It can speed up drafting, coding, and refinement, but the final decisions still need to come from the person whose work and reputation the portfolio represents.

The final site is now more complete and practical. It includes a polished main portfolio, previous version archive, downloadable resume, and a mobile connect page that can be used in real professional situations.
